# IWSO 2027 — 投稿者向けマニュアル

Abstractの投稿、状況確認、採否の確認までの一連の流れを説明します。

## 1. サインイン方法

IWSO 2027はパスワード不要のログイン方式です。事前のアカウント登録もパスワードの記憶も不要です。

1. サインインページでメールアドレスを入力します。
2. **Send sign-in link** をクリックします。
3. 届いたメール(送信元: IWSO 2027)内のリンクをクリックします。
4. 自動的にサインインされます。リンクには有効期限があり、1回しか使えないため、うまくいかない場合は再度メールを送信してください。

初めてサインインした時点で自動的にアカウントが作成されるため、別途の登録手続きは不要です。

> 補足: 迷惑メール対策として、同じメールアドレスへの送信は1分に1回までに制限されています。直前にリクエストした場合は1分ほど待ってから再度お試しください。

## 2. Abstractの投稿方法

1. サインイン後、上部メニューの **Submissions** → **New Submission**(またはトップページの **Submit an Abstract**)を開きます。
2. 以下を入力します。
   - **Title**(タイトル、必須)
   - **Track**(トラック、必須)— 内容に最も近い分野を選択
   - **Presentation Type**(発表形式)— Oral(口頭発表)またはPoster(ポスター発表)
   - **Keywords**(キーワード)— 最大10個。後の検索・絞り込みに使用されます
   - **Authors**(著者)— 氏名・メールアドレス・所属(任意)を全著者分入力し、責任著者(Corresponding)にチェック
   - **Abstract PDF** — AbstractをPDFファイルでアップロード(**最大10MB**)。タイトル・著者・所属は上記のテキスト欄に入力するため、PDF自体には本文のみ含まれていれば問題ありません。
3. 以下のいずれかを選択します。
   - **Save Draft**(下書き保存)— 入力途中の内容を保存します。後で続きから編集できます。下書きは査読には回りません。
   - **Submit**(投稿)— 投稿を確定し、査読に回します。投稿確定にはPDFのアップロードが必須です。

初めて投稿(Submit)が完了した際に、確認メールが届きます。

## 3. 編集・取り下げ

**Submissions** ページで、自分の投稿一覧とステータスを確認できます。

- ステータスが **Draft** または **Submitted** の間(査読者がアサインされる前)は、詳細画面を開いて内容を自由に編集でき、PDFの差し替えも可能です。
- **Withdraw**(取り下げ)は、採否が確定する(**Decided**になる)までであればいつでも可能です。**Under Review**(査読中)の間も取り下げられます。**Decided**になった後は取り下げできません。
- 取り下げは元に戻せず、取り下げた投稿を復活させることもできません(必要であれば新規に投稿し直してください)。

## 4. ステータスの意味

| ステータス | 意味 |
|---|---|
| Draft | 下書き保存済み、未投稿 |
| Submitted | 投稿済み、査読者未アサイン |
| Under Review | 査読者が1名以上アサインされ、査読中 |
| Decided | Chairが採否を確定済み |
| Withdrawn | 取り下げ済み |

## 5. 採否の確認

Chairが最終的な採否を確定すると、**Accept(採択)** または **Reject(不採択)** の結果と、査読者が著者向けに残したコメント(Chair宛の非公開コメントは含まれません)がメールで届きます。メールを待たずとも、**Submissions** ページでいつでも結果を確認できます。

## 6. 見えない情報について

公正な査読プロセスを保つため、投稿者からは以下が見えないようになっています。

- 誰が査読したか、およびそのスコア
- 査読者からChair宛の非公開コメント
- 会議プログラム(正規の学会公式サイトで別途公開されます)
