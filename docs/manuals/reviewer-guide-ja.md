# IWSO 2027 — 査読者向けマニュアル

サインイン方法から、担当投稿の確認、査読の提出までを説明します。

## 1. サインイン方法

IWSO 2027はパスワード不要のログイン方式です。事前登録やパスワードの記憶は不要です。

1. サインインページでメールアドレスを入力します。
2. **Send sign-in link** をクリックします。
3. 届いたメール(送信元: IWSO 2027)内のリンクをクリックします。
4. 自動的にサインインされます。リンクには有効期限があり、1回しか使えないため、うまくいかない場合は再度メールを送信してください。

査読者としてアサインされている場合は、Chairが登録したものと同じメールアドレスでサインインしてください。

> 補足: 迷惑メール対策として、同じメールアドレスへの送信は1分に1回までに制限されています。

## 2. 担当投稿の確認方法

上部メニューの **Review** を開くと、**Review Queue**(査読キュー)が表示され、現在自分にアサインされている投稿が一覧され、それぞれ **Pending**(未査読)または **Reviewed**(査読済み)のバッジが付いています。

新たに投稿がアサインされると、その一覧が記載されたメールが届きます。同じタイミングで複数件アサインされた場合は、1件ずつではなく、まとめて1通のメールで届きます。

## 3. 査読の提出方法

1. Review Queueから、査読したい投稿のタイトルをクリックして開きます。
2. タイトル・トラック・キーワードとあわせて、Abstract(PDF)をダウンロードして内容を確認します。
3. 査読フォームに入力します。
   - **Score (1–5)**(スコア、1〜5)
   - **Recommendation**(推奨)— Accept(採択)またはReject(不採択)
   - **Comments for Author**(著者向けコメント)— 採否通知時に著者へ共有される可能性があるため、建設的な内容を心がけてください
   - **Confidential Comments for Chair**(Chair宛の非公開コメント)— 運営(Chair)のみに表示され、著者には共有されません
4. **Submit Review** をクリックします。

Chairが最終的な採否を確定するまでは、いつでも内容を修正して再提出できます。再提出しても重複登録にはならず、既存の査読内容が更新されます。

## 4. 利益相反(COI)について

自分が著者、または投稿者として登録されている投稿については、査読者としてアサインされることはありません。システムが自動的に防止しています。

## 5. リマインダーについて

未完了の査読がある場合、Chairからリマインダーメールが届くことがあります。特別な対応は不要で、可能なタイミングで査読を完了してください。

## 6. 見えない情報について

公正な査読プロセスを保つため、同じ投稿に対する他の査読者のスコアやコメントは見ることができません。また、会議プログラムはこのシステム上には公開されません(正規の学会公式サイトで別途公開されます)。
